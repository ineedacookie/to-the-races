# Pixel UI icons

## Nickname dice

`dice-source.png` is JamesWhite's CC0 low-resolution dice sheet. `dice.png` is a
16×16 nearest-neighbor crop of its five-pip face, displayed with pixelated scaling
on the random-nickname button.
